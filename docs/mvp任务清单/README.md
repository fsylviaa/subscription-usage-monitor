## 1. MVP 会实现什么

| 模块 | 你最终能做什么 |
|---|---|
| Codex 登录与多账户 | 连接已有账户；同页查看多个账户；移动排序、重复添加去重和断开 |
| 额度看板 | 常显平台实际套餐名称，再看适用的周／5 小时真实额度；正常无适用额度与获取失败分别显示 |
| 自动与手动更新 | 打开／返回 App 自动刷新；下拉刷新全部或从卡片菜单刷新单账户；后台按 30 分钟目标尽力更新 |
| 失败恢复 | 按既定网络检查执行；失败保留可信旧数据，简短提示并能重试 |
| 桌面小组件 | 添加小号、中号；默认首项、系统编辑选账户；显示实际套餐及适用额度；点击进入对应内容 |
| 重置提醒 | 全局开关；依据真实时间收到预计重置提醒；点击打开对应账户 |
| 教程、设置与外观 | 两步组件教程、必要帮助／隐私／开源许可；App 默认跟随系统、手动选择持久优先；组件跟随系统浅深外观 |

其他平台、ChatGPT 聊天额度、API 余额、历史统计、锁屏小组件、低额度预警及额外设置均不加入本次范围。
