## 你怎么验收

| 操作 | 预期结果 |
|---|---|
| 开发者在当前真实网络运行一次取分，出示去敏结果摘要。 | 结果明确标为指定来源的有效评分或无法取得；不能用一般连通性或其他评分替代。 |
| 开发者分别输入固定结果 49、50、51，运行判断检查。 | 49 和 50 阻止后续操作；只有 51 允许继续。 |
| 开发者输入缺失、格式无效、超时等取分失败结果。 | 全部阻止；“未知”不被写成 0 分或有效低分。 |
| 开发者在隔离环境执行“取消检查”，再让测试检查返回成功。 | 已取消操作不被迟到的检查结果继续启动。 |
