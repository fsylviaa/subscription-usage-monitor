## 本次交付

设置最底部可开关演示添加；开启后从额度页连接入口反复新增不同示例账户，无需真实登录。关闭清除全部演示账户，真实账户和数据不变。

## 范围与实现边界

- 演示开关只改变新账户来源，真实账户仍显示并保持原有实际行为；不新增演示看板或用户填写技术参数的步骤。
- 自动提供不同样例身份和额度，以简短演示标识区分。样例用独立来源标记，不保存伪造的真实授权，不调用真实身份／额度服务。
- 提供演示刷新与删除的本地处理能力；卡片正式菜单分别由 T25／T21 接入，同一个入口按账户来源选择正确处理。没有完成对应任务时不宣称菜单已完成。
- 演示重开与排序共用正常流程；关闭开关后清除全部样例及其结果，阻止迟到模拟结果写回。保留真实账户、授权、快照及真实账户相对顺序，不发模拟额度通知。

## 验收

| 操作 | 预期 |
|---|---|
| 开启后从额度页连续添加至少三次 | 不出现真实登录；不同样例身份及额度，追加末尾，无固定样例数上限 |
| 有真实账户时开启、添加，随后关闭 | 真实账户及授权／缓存不变；所有演示账户消失 |
| 关闭后彻底重开，再重新开启 | 已清理样例不复活；可添加新的演示账户 |
| 开启期间重开 App | 开关与已添加样例保持，身份／数据不串到真实账户 |
| 开发者在隔离环境模拟样例刷新、删除及清理中断 | 仅目标样例变化，重试清理安全，迟到结果不复活样例；不访问真实凭据／真实网络 |
