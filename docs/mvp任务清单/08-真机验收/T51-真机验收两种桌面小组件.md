## 本次交付

用户在自己的主屏幕实际使用小号与中号组件，能确认显示、更新和点击归属正确。

## 本次范围

验收真实系统小组件及已有状态逻辑，不增加锁屏组件、账户选择器或更多尺寸。

## 验收准备

手机 App 中已有 A/B 两账户；小组件扩展随当前 App 构建安装。开发者另备独立测试构建及隔离共享容器，演示无额度、替换、移除和空态；保留真实日常连接及其通知、续期观察链，不清空真实数据。

## 你怎么验收

| 操作 | 预期结果 |
|---|---|
| 长按主屏幕，搜索本 App，分别添加小号和中号。 | 两种都能实际添加，均显示首账户的周/5小时真实可用窗口、身份、重置和成功时间。 |
| 在 App 刷新首账户，随后查看两种组件。 | 系统更新后内容来自同一成功快照；如系统延迟，记录请求与实际显示时间，不宣称即时切换。 |
| 先在真实 App 把 B 移到首位；替换或移除首项改在隔离测试构建中演示。 | 准备的新身份、额度、点击目标一致并请求所有组件更新，系统显示后均跟随首项，无账户选择步骤。 |
| 在独立测试构建及共享容器中运行首项无额度场景，再移除该隔离环境的全部测试绑定。 | 前者显示“尚未获取额度”且不跳到第二项；后者显示“未连接账号，无数据”。真实日常账户、通知安排和续期观察均保持。 |
| 切回真实 App 及其组件，点击正常组件；旧画面指向已移除账户的情况由开发者在隔离环境复现。 | 有效目标进入对应账户并自动刷新；失效目标进入当前有效页/无账户页，不恢复删除数据。 |
| 切换系统浅深外观，查看两尺寸的正常、失败旧数据和空态。 | 文字清楚，剩余70%时实色已用30%；无数据无假比例，失败不刷新成功时间。 |
