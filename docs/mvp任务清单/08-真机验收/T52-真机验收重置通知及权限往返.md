## 你怎么验收

| 操作 | 预期结果 |
|---|---|
| 关闭再开启全局提醒，并经历允许或拒绝权限后的系统设置往返。 | 开关持久保存；拒绝后不反复弹权限框，返回 App 反映实际权限。拒绝场景可引用同机独立测试安装证据，不强制清除日常数据。 |
| 开启后重复刷新，查看开发者给出的待发提醒摘要。 | 每账户/窗口/本轮只有一份；无有效时间不安排，新加入账户沿用全局开关。 |
| 保留真实即将重置的安排，在系统允许的条件下锁屏等到该时间，再查看通知。 | 收到可识别账户和窗口的“预计重置，打开查看”提醒，不说已恢复100%。没有实际送达证据时该步待验。 |
| 点这条真实通知。 | 打开对应账户并自动更新，显示查询后的真实结果。 |
| 使用另一次真实有效的待发安排，关闭开关，或断开/替换该身份；查看开发者给出的待发摘要。 | 相应待发项已取消或按新有效身份重新安排。虚拟通知中心的改时/去重测试可补充，不能冒充系统真实通知。 |
| 点击仍留在通知中心、但对应账户已删除的历史通知（如已有），或查看该路径的隔离测试结果。 | 进入当前有效状态，不把旧通知当作另一身份、不恢复已删除数据；证据类型明确。 |
