## 你怎么验收

| 操作 | 预期结果 |
|---|---|
| 查看 T30/T31 起收集的真机自然后台执行结果，核对当时 App 未在前台。 | 至少一次系统实际执行时完成网络检查和查询，并保存成功快照；调试手动触发标记单独列出，不能替代这条证据。 |
| 对照更新前后 App/组件的成功时间和内容。 | 成功后数据来自新查询；组件实际更新可有系统延迟，不能仅因本次额度数值相同判定未查询。 |
| 查看开发者准备的后台低分、未知或查询失败测试结果。 | 不查询或失败时保留旧值和原时间，不自动打开浏览器或弹前台窗口。此项注明为可控故障测试。 |
| 在后台刚完成更新后打开 App。 | 前台独立发起更新，不因缓存新或周期未到而跳过；相同在途请求可复用。 |
| 查看一次执行被系统结束后的测试结果与后续调度。 | 已完成账户的可信成功结果保留，未完成账户不假成功；后续仍能请求执行机会。 |
