## 你怎么验收

| 操作 | 预期结果 |
|---|---|
| 退出再打开 App，刚完成刷新后切出去再返回。 | 每次进入都自动更新，不等30分钟；进行中相同请求可复用，页面先显示可信数据；自动过程无转圈／更新条／成功提示。 |
| 点 A 卡片刷新，再点顶部刷新。 | 第一次只作用于A，第二次作用于全部账户；仅本次目标卡片套餐箭头右侧转圈，各户结束各自停止，重试维持原范围。 |
| 在开发者准备的一户失败场景点全部刷新。 | 成功账户更新，失败账户原值原成功时间保留；只出现简短失败反馈。 |
| 分别验收 49、50、51 和无法取得评分的场景。 | 49/50 显示网络不达标并阻止；51 才可继续实际查询；未知阻止且显示刷新失败。连接前有对应“无法连接”提示，未建立假账户。 |
| 失败后点右上角“×”，切换页面再回来，然后再发起一次更新。 | 整条连同按钮消失，列表收紧；同次提示不重现；新一次失败重新显示、成功立即隐藏。原时间不因关条改变。 |
| 更新期间及失败后查看顶部。 | 手动和自动更新均无顶部更新条或取消刷新；失败才显示可关闭的信息条及原范围重试，不提供重新登录入口或建议。 |
| 开发者延迟单卡／全部检查及查询，随后让结果成功。 | 手动操作仅卡片小转圈，自行结束后停转并更新数据，无成功提示；不提供取消按钮。登录流程保持原规则。 |
