## 你怎么验收

| 操作 | 预期结果 |
|---|---|
| 先添加 A，再添加 B，查看额度列表。 | 按 A、B 显示，两张卡身份和额度分别对应，数据没有相加或串用。 |
| 把 B 移到 A 前面，退出重开，再查看额度页。 | 额度页仍为 B、A，顺序持久保存；没有设置账户管理子页。 |
| 从添加入口再次连接 A。 | 始终只有一条 A，保留其位置，采用最新成功连接；不报重复账户错误。 |
| 从添加入口先取消一次，再完成连接已有的 B。 | 取消后原列表保留；成功后只更新 B 的连接，A 不变；不继承其他账户额度。 |
| 重新添加 A 后断开 A，退出重开。 | A 不再出现，B 正常使用；不会取消 A 的平台订阅或退出官网其他会话。 |
| 观看开发者运行延迟旧请求的隔离验收场景。 | 断开或替换后旧结果不能恢复 A 或覆盖 B；此行注明为可控测试。 |
