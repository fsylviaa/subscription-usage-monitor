## 本次交付

在连接入口点击后，App 先检查网络；通过后显示平台所需的一次性代码，能复制并打开系统默认浏览器中的官方确认页面。

## 范围边界

- 只做连接前检查、申请代码、复制和打开官网这一个连接起点；界面沿用固定原型中适用的入口和简短等待反馈。
- 本任务不把打开网页算作连接成功；正式保存账户由 T08 完成。不增加平台选择、浏览器选择、扩展安装、API key 输入或评分介绍页。

## 验收准备

- 开发者提供可运行构建；准备已有 OpenAI 账户及手机当前默认浏览器。
- 开发者提供隔离测试场景“连接评分 50 / 51 / 未知”和可控慢检查；测试不写入真实账户。真实网络没有通过时如实记录，不能绕过检查完成真实连接。

## 项目经理怎么验收

真实操作与隔离测试分开记录；开发者负责准备和运行具名测试，不让项目经理改代码、读网络日志。测试构建不新增正式产品页面。

| 步骤 | 操作 | 应该看到的结果 |
|---|---|---|
| 1 | 真实流程：从无账户页或额度页点击“连接 Codex”。 | 显示必要的连接中反馈；检查通过后自动进入代码步骤，不要求再点“检查通过”。 |
| 2 | 点击复制，再点击打开官网；在官网需要代码处粘贴。 | 代码与 App 显示的一致；使用系统默认打开行为到达 OpenAI 官方设备确认页面；不把代码当成 API key。 |
| 3 | 隔离测试：分别运行评分 50 与 51 的连接场景。 | 50 显示“网络不达标，无法连接”，不申请登录代码、不打开授权；51 继续申请代码。 |
| 4 | 隔离测试：运行评分未知或申请代码失败场景。 | 显示“登录未完成，请重试”等简短结果；不报假低分、不添加账户、不显示连接成功。 |
| 5 | 隔离测试：慢检查期间点取消，再让检查返回通过。 | 回到原来源；迟到结果不会继续申请代码或打开浏览器。 |

## 开发说明（实施时阅读）

- [技术连接方案](../../首版平台登录与额度连接方案.md) §3.3、§3.5、§4.2：复用 T06 的指定评分检查，实际授权前必须通过；申请设备码后保存本次事务的必要字段和原始到期边界。
- 按技术方案固定的官方设备码协议快照实现申请请求；校验代码、轮询间隔与地址。只在平台确实支持完整含码 URL 时使用，不编造自动填码。
- 系统 HTTPS 打开能力尊重默认浏览器；不读取浏览器 Cookie，不探测或要求安装指定浏览器。授权领回与正式账户提交交给 T08。
- 复制是用户主动操作；代码只用于本次授权，不打印至日志、验收截图或 Git。测试记录只需给出是否复制一致、是否发起授权。
