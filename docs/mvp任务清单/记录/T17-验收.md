## 用户怎么验收

新版已安装，先解锁手机让开发者补完真机自验；收到自验完成通知后按下面三步亲验：

1. 打开手机「订阅用量 → 设置 → 账户管理」。按住末尾账户右侧的三横线把手，拖到第一位后松手；账户身份应一起移到首位，无需另点保存。
2. 切到「额度」，确认账户顺序一致；再进入账户管理，顺序仍一致。
3. 从多任务界面彻底关闭 App，再重新打开；两个页面应保留新顺序。可以再拖回自己喜欢的顺序。
4. 如果之后需要添加另一个已有的不同账户，添加成功后应在当前列表末尾。三账户局部移动、排序后新增和失败保护由开发者隔离测试负责，无需为验收注册新账户。

本轮不要求核对五小时／周真实余额、重置时间或重新登录，也不把隔离样例视为真实平台数据通过。
