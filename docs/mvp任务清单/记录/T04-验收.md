### 实现与边界

- `ConnectedAccount.id` 为稳定本地 ID；邮箱不充当主键，`remoteUserID` 与 Codex 查询所用的 `scope.remoteAccountID` 分开；账户普通文件不保存登录秘密。
- 账户数组位置是唯一持久化顺序，避免再维护一个可能冲突的 displayOrder。追加、原位置更新与完整重排均由同一个 AccountStore actor 串行执行；整份带版本 JSON 使用原子替换写入。
- 无文件与读取失败分开处理；损坏/未知版本不自动清空。写入失败直接返回错误，没有提前发布的内存状态或伪成功时间。
- 独立 `AccountQuotaState.notFetched` 只表示尚未取得额度。真实窗口语义/成功快照留给 T11/T12；没有提前实现额度解析、登录、邮箱去重、重连、移除、页面排序或小组件。
- 本次恢复检查是**新建存储实例从磁盘读取**，不是 T15 的真实登录后离线重开 App 验收。路径故障测试可能在读取阶段失败，不声称已经模拟写入中断或断电；实际原子写入采用 Foundation 的 `.atomic` 能力。
- 首次沙箱构建因 CoreSimulator 服务访问限制退出 70；使用本机开发工具许可后构建、测试成功。测试没有失败项，不把最初环境失败记录为成功。
- 页面代码未变，本次未重复 UI 自动化、浅深外观或真机安装。文件保护在真实设备重启/解锁后的表现尚未实测，不把模拟器结果当作此项真机证据。
