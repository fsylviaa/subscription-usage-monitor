# T61 小组件自主更新验收

日期：2026-10-11。代码已实现；自然运行效果待观察，未冒充完成。用户亲验：部分通过（2026-10-11用户确认App后台更新后桌面显示新数字；自主取数来源及多日自然效果未单独确认）。

## 本次实施

用户接受“日常无需手动操作，也会自动更新”，不要求固定分钟间隔。组件在系统给予时间线机会时读取当前配置的账户，通过与App相同的网络评分、查询、身份验证、解析和授权续期取得结果；成功保存共享数据再返回展示。已有新鲜结果直接复用，多尺寸同账户合并查询。Provider由`.never`改为`.after(30分钟)`申请下一次机会，不是定时保证。

保留App前台立即自动刷新、后台任务补充。可见内容变化仍请求更新；进入后台时合并补发一次。App冷启动即使数据未变也补发一次，给旧版`.never`时间线建立新的读取机会；普通重复读缓存不反复请求。未新增按钮、设置、服务器、登录入口或T36功能。

账户元数据移入App Group，由App首次校验并复制原文件；保留原文件，后续以共享文件为准，损坏不回退旧版。沿用原App默认Keychain访问组，扩展获得同组权限，秘密不复制到普通文件。文件互斥保护两进程读改写及凭据比较替换，单账户查询占用记录合并重复请求，90秒失效后可接续；保存前验证占用仍属于本次请求，失效请求不能写入成功或失败。网络等待不持有OS文件锁，避免App暂停时阻塞组件；授权续期仍通过原持久标记及绑定比较替换防重放。失败保留可信旧额度和原成功时间；尝试时间不会当成成功时间。账户选择仍由系统保存，未修改配置。
