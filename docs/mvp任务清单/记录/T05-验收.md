### 实现边界

- `CredentialVault` 提供按 `credentialRef` 保存、读取和删除正式授权，临时登录资料使用独立命名空间。
- 完整 `CredentialPayload` 保存在一个 Keychain 条目中；已有值一次更新，不先删后存。仅本机使用，首次解锁后可访问，不通过 iCloud 同步，不配置共享 Keychain group。
- 仅确实不存在时返回 nil；暂不可读和其他错误分别上报，不删除原授权，不访问或修改账户文件。错误只含内部类别和系统状态码，不带包内容。
- 本次保存整包 Data，不提前固定平台协议。Codex 适配器在后续登录/续期任务编码真实字段、版本、时间和已验证绑定；临时事务到期、一次消费、登录提交和删除重试编排也留对应后续任务。
- Swift 6 构建及独立静态复核通过；最初模拟器查询受到沙箱服务访问限制，取得本机开发工具许可后正常使用，没有将环境失败写成测试通过。

### 固定操作与实际结果

下列存取与故障保护在模拟器、实体 iPhone 上均通过；使用的仍是虚构授权，不是用户真实 Codex 登录。

| 操作或固定输入 | 预期 | 实际结果 | 结论 |
|---|---|---|---|
| 保存 A、B，结束写入实例后新建读取实例 | 两份都在且各自匹配 | A 存在且匹配，B 存在且匹配 | 通过 |
| 只替换 A 的完整授权包，再读 A、B | A 采用新包，B 不变 | A 完整字节匹配新包且不匹配旧包；B 匹配原包 | 通过 |
| 只删除 A，再重复删除 A | A 不存在，B 仍可用；重复删除可安全处理 | A 不存在，B 存在且匹配，两次删除均成功返回 | 通过 |
| 注入两种临时不可读状态，随后恢复系统读取 | 返回暂不可读，不能当作已退出或清数据 | 恢复后 A/B 匹配原包；普通账户文件逐字节不变，账户与原状态不变 | 通过（注入故障） |
| 检查日志、描述、普通存储与提交差异 | 不展示授权原文，不写进普通文件/Git | 生产存取无日志/普通文件写入；描述与反射去敏；布尔断言和四行状态摘要不含包内容；两次运行日志无运行时授权标记；普通账户文件只有引用 | 通过 |
| 正式和临时条目使用同一 UUID，更新并删除临时条目 | 两者互不覆盖 | 临时条目更新/删除后正式授权仍匹配 | 通过 |
| 从实际测试条目读取属性 | 本机首次解锁后可读，不跨设备同步 | 正式与临时项的 accessible、synchronizable 均匹配既定属性 | 通过 |
| 注入更新、删除和首次保存失败，恢复后读取/重试 | 不报告伪成功、不抹旧包、不改其他账户 | 更新失败保留 A/B 原包；删除失败保留原包且恢复后可重试；账户文件不变；首次保存失败不生成空条目 | 通过（注入故障） |
| 读取不存在项、其他错误、无效读取结果，或尝试保存空包 | 不存在与失败分开；无效包不覆盖旧值 | nil 仅用于确实不存在；其他失败正常抛错；旧包恢复后仍匹配 | 通过 |
