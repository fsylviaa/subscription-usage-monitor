# T08 验收记录

**隔离功能、真机页面与浅深外观已通过；真实账户登录、保存和重开仍待完成。当前不能宣布 T08 整体通过。**

## 用户需要配合的真实登录

手机已安装 T08 并恢复普通启动，不用操作 Xcode 或读日志。

1. 打开“订阅用量”，点 **连接 Codex**。网络检查通过后，点 **复制代码 → 打开官网**。
2. 本人在官网完成登录与代码确认，然后回到 App。密码、验证码和一次性代码不要发给开发者。
3. App 应自动完成核验，显示本次账户的可靠邮箱与 **尚未获取额度**；没有“我已登录”按钮。
4. 完全关闭 App 后从桌面重开，邮箱应仍在，仍为 **尚未获取额度**。本步没有正式额度查询，不应出现百分比、套餐或假的成功更新时间。

完成官网步骤后告知页面结果，开发者继续读取本 App 自己保存的账户与授权，向官方服务重新核验并检查重开。此配合不自动记为用户正式验收通过；开发者通过后再请用户对照上述页面亲验。

### 身份核验依据

1. 设备码继续使用 T07 的官方 Codex 固定快照 `165299214855c2e48facf9bb3bc3c0fc277ee639`：[设备流程](https://github.com/openai/codex/blob/165299214855c2e48facf9bb3bc3c0fc277ee639/codex-rs/login/src/device_code_auth.rs)、[授权交换](https://github.com/openai/codex/blob/165299214855c2e48facf9bb3bc3c0fc277ee639/codex-rs/login/src/oauth/client.rs)、[身份字段](https://github.com/openai/codex/blob/165299214855c2e48facf9bb3bc3c0fc277ee639/codex-rs/login/src/token_data.rs)。403/404 仅在轮询时是等待；成功响应的 code/verifier/challenge 对应后交换，不重复交换单次码。
2. 2026-10-10 公共 GET 核对 [官方 discovery](https://auth.openai.com/.well-known/openid-configuration) 和 [JWKS](https://auth.openai.com/.well-known/jwks.json)：issuer 为 `https://auth.openai.com`，签名算法 RS256，JWKS 当次 4 把 RSA 公钥。没有发送用户凭据。
3. [官方身份验证说明 §6](https://developers.openai.com/siwc/website) 与 [Token reference](https://developers.openai.com/siwc/token-sharing-open-source/token-reference) 为签名、iss/aud/exp/iat/sub/client 校验依据；它们不证明本 App 的第三方客户端资格，实际设备码接受情况必须真机证明。
4. App 通过固定 HTTPS JWKS，用系统 Security 验证 ID 和 access token 签名，核对 issuer、client/audience、有效期及相同 subject。只采用已签名的邮箱与 account/user 声明；直接 JSON 解码、网页成功和非空 token 均不够。
5. 再执行 T06 指定网络检查，使用本次 access token 和已验签账户 ID，访问固定 `https://chatgpt.com/backend-api/wham/usage`，要求响应 account_id 相同；如返回 user_id/email 也须匹配。只解码身份字段，不发布额度快照。未知或不匹配时失败，不换其他作用域凑数。
6. 正式凭据包保存版本、签发者、client、subject、用户、作用域和本次 token；敏感数据仅在本 App 钥匙串及内存。普通账户文件只留身份及 credentialRef。日志只含固定阶段，测试报告不记录真实邮箱或 token。

### 发现与修正

独立存储审查发现取消后提前清空 pendingID 可能丢失迟到临时写入的清理机会。已改为保留引用，重试先等待旧工作结束再清理；不覆盖新事务。另补服务端返回邮箱时与签名邮箱一致的检查，修改后在真机重跑 11 项身份核验测试全部通过。最终还将临时存储默认注入改为 nil、仅普通启动显式组装真实存储，避免旧 T07 测试触达正式命名空间；受影响的 25 项模拟器流程检查通过。两次独立只读审查未发现范围内阻断问题；审查不能替代真实登录。
