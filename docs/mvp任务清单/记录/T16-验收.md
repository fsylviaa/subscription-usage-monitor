## 本次变化

开放已有账户后的连接入口。新身份核验和独立授权保存成功后，追加在原账户末尾；额度页同屏分别展示，“设置 → 账户管理”读取同一列表。身份、授权引用、套餐、额度快照和成功时间各自保存，不设全局当前账户或汇总余额，不限制样例数量。

保留首次查询前原网络检查。多个未获取账户在重开后依次补齐；后一个成功不会清除前一个失败状态和重试入口。新增登录失败或取消保留原账户及凭据。已有账户缓存可以先阅读，但连接入口独立等待原登录恢复，避免开启第二条登录流程。

添加第二账户中途关闭后，恢复原登录事务；普通元数据中的可选本地事务 UUID 用于识别已提交但尚未清理的事务，防止再次添加同一事务。该字段不是登录令牌，旧文件缺字段仍可读取。

## 用户怎么验收

交付时手机安装新版并恢复普通入口，正式账户保留。以下只验收多账户添加与保留，暂不对照真实五小时余额。

1. 打开手机“订阅用量”，确认原账户仍在。
2. 点额度页右上角连接按钮，复制代码并打开官网，**使用另一个已有 Codex 账户**完成登录确认，再返回 App。应看到原账户在前、新账户在后，两条邮箱各自正确。若浏览器仍登录原账户，需在官网使用要添加的另一个账户完成本次确认。
3. 打开“设置 → 账户管理”，应看到相同的两个账户和相同顺序。
4. 从多任务界面完全关闭 App 后重新打开，两账户、顺序及已有显示结果应保留，无需再次登录。

无需购买订阅或制造网络故障；B 失败保护、不同数值归属和六账户滚动由开发者提供隔离证据。符合以上四步可反馈“T16 本阶段验收通过”。真实周／五小时数值、重置时间及此前 T12／T13／T15 的相关对照仍留增删就绪后补验，不能因本阶段通过而取消。
