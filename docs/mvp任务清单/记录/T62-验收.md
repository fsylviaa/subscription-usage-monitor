## 字段来源核查与实际支持

| 字段 | 来源、单位及处理 |
|---|---|
| 套餐 | 现有wham/usage的plan_type，经AccountSubscription校验保存；显示实际文本，失败单独保存套餐不会伪造额度成功时间 |
| 5小时／每周 | 现有rate_limit窗口，以limit_window_seconds识别18000／604800秒；used_percent是已用0～100，剩余=100−已用；真实0、100均保留，缺失仍未知 |
| 预计重置 | reset_at Unix秒，经现有解析校验；缺失仍“未提供重置时间”，到点只显示“已到预计时间”，不改满 |
| 更新时间 | 当前身份、作用域、版本匹配的已保存成功快照observedAt，本地成功查询完成时间；不是截图时间，也不是套餐单独更新的时间 |
| 模型专项、Code review | 当前解析及持久快照没有这些已校验字段；未获得本次账户可可靠展示的保存值，整行隐藏。不从模型名单、主窗口或截图推断 |
| 额度、无限额度、重置额度 | 官方CreditsSnapshot包含has_credits／unlimited／balance，但它不是主订阅百分比，balance字符串不能从该类型确认截图数字的单位；“重置额度”也没有确认的计数语义。本次不建立字段映射、不显示行，false／0不伪装成缺失或其他额度 |

核查依据：现有CodexUsageParser及领域／存储实现；2026-10-12只读核对[OpenAI官方协议类型](https://github.com/openai/codex/blob/main/codex-rs/protocol/src/protocol.rs)的RateLimitWindow／CreditsSnapshot（已用百分比、窗口分钟、Unix秒与独立credits定义）及[官方backend-client](https://github.com/openai/codex/blob/main/codex-rs/backend-client/src/client.rs)。当前App沿用wham原始字段名与秒窗口，未混用转换后协议字段。来源仅支持上述有限结论，未据此宣称所有补充字段已可靠接入。
