## 本次行为

小号／中号组件的点击URL来自它实际渲染的快照，包含本地账户UUID及身份摘要，不携带邮箱正文、远端scope或授权。默认首项与系统编辑的指定账户都用同一规则；不按点击时列表下标重新选人。

App在缓存读取完成后解析目标并打开T62面板；冷启动不会等未完成的登录恢复。后台返回也用同一面板。仍有效的旧目标保持原账户；删除、deletionPending或同UUID身份已变化、非法目标安全回额度页；没有有效账户进入已有连接入口，不新增选择页面或恢复记录。打开面板和路由都不调用查询，前台激活沿用T27／T28自动触发及合并。

## 历史失败与修正

1. 首轮系统URL页面两项失败：Home返回后的瞬间App仍标foreground，及空态检查用了不存在的platforms.title。改为等待实际后台状态、读取既有platforms.codex；两端后续通过，无产品语义绕过。
2. 自审发现用整个loadAccounts完成作为路由门槛，会等登录恢复；改为发布已有可信缓存读取完成状态，专门挂起恢复60秒核对立即打开，双端通过。
3. 只读清理检查首次编译缺主线程标注（同一缺项两次构建失败），补齐后构建及显式手机核对通过。原失败日志保留。
4. 复审T62纯时间格式函数的actor标注警告，改为nonisolated纯格式函数；最终Release编译通过，未改时间值或样式。原有不相关设置／测试代码警告未作为本任务扩展修复。
