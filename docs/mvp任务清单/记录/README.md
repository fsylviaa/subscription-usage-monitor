# 验收记录存放处

本目录按实际执行情况创建记录，不预建虚假的通过记录。当前任务状态和待验事项统一查看 [项目进度](../../项目进度.md)。

执行任务时按[执行约定](../执行约定.md)创建 `Txx-验收.md`，记录操作、预期、实际结果及真实/测试环境区别，与该任务、状态及项目进度一起提交 Git。用户亲自验收状态单独记录。待验、受阻和不通过必须如实保留；后续修复、复验和用户反馈按日期追加，并写明剩余工作和继续位置。

自然后台执行、真实通知或授权到期观察由开发者在相关开发任务开始留存去敏证据，后续验收任务引用同一证据，不重复创建用户操作或产品页面。
