## 本次范围

D-61（2026-10-11）：沿用额度列表现有跟手下拉，顶部固定；拉出的顶部空间显示不旋转的小圆圈，随距离适度放大并封顶。达到触发距离轻震一次，松手时仍超过触发距离才全量刷新；不足或收回距离以内仅回弹。顶部圆圈随回弹收起，后续由卡片小转圈显示手动刷新进度；成功无提示，失败保留原规则。无账户、刷新中和卡片排序不重复触发。

复用已有全量刷新链和原生滚动回弹，不改登录流程、排序规则或自动触发时机；不新增设置、状态文字或取消按钮。具体手感在真机自验调整，不把像素及动画时长写死为需求。

## 验收

| 操作 | 预期 |
|---|---|
| 列表顶部轻拉，不够距离就松手 | 圆圈随下拉放大，卡片回弹，不刷新 |
| 拉到触发距离并继续保持手指 | 轻震一次，圆圈保持静态且大小封顶，未发起请求 |
| 超过触发距离松手 | 卡片回弹、顶部圆圈收起，所有目标卡片显示进度并各自结束 |
| 拉过距离后收回距离以内再松手 | 不刷新，不改变额度与成功时间 |
| 同一手势往返穿过门槛 | 只轻震一次，是否刷新以松手位置决定 |
| 刷新中再拉、普通滚动、长按排序 | 不新增刷新或误触；排序和详情展开保持 |
| 部分失败及重试 | 成功独立更新，失败旧值／时间保留，失败可关闭并按全量重试 |
| 浅深色、最大字号、真机 | 圆圈可见但保持小尺寸；标题固定，卡片跟手和回弹自然 |

开发者用隔离数据准备边界检查；本人用两个演示账户检查轻拉／充分下拉／收回后松手及震动手感，无需制造网络故障或做真实五小时对照。
