# 新拟态＋玻璃拟态额度页参考

这是“订阅额度”首页的独立静态 HTML 视觉参考，不修改或替代当前 iOS App 实现，也不改动只读 Figma 文件。

## 查看方式

直接用浏览器打开 [`index.html`](index.html)。页面按原稿 `828 × 1792` 竖版比例缩放，使用纯 HTML、CSS 和本地图片资源，不需要安装依赖或连接网络。

## 本版约束

- 保留原稿全部文字、页面层级、卡片位置、比例、状态栏和底部导航。
- 使用浅灰背景、低饱和雾蓝环境光、半透明磨砂玻璃、新拟态内外阴影和高光边缘。
- Cursor 与 DeepSeek 卡片右侧的灰色品牌图形沿用原稿轮廓，不使用近似重绘形状。
- 本目录仅用于视觉评审；是否进入原生 App 需后续按项目任务单独授权、实现和验收。
