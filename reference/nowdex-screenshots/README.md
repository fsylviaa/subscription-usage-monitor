## 设计参考约定

- 优先参考连接入口、额度卡片、演示模式、小组件和教学流程。
- 截图的深色来自用户手机的系统设置；我们的产品需要完整设计浅色和深色，并自动跟随系统。
- 截图中的 Tokens、历史统计、其他平台、购买和 iCloud 等功能不自动进入我们的第一版。
- 教学截图只是动画的部分画面，不代表完整动画时序；演示额度不是已验证的真实接口数据。
- 保留所有相近截图，便于回看不同滚动位置和细节。
