## 用户最终会看到什么

平台选择弹层多一个Cursor图标；登录Cursor后额度页出现Cursor卡片，只有一条“本月”剩余百分比；13款样式、详情、小／中号组件、刷新、重置提醒、演示都支持Cursor。所有平台（含Codex）不再显示套餐名。

## 拆分思路

先验证最大的不确定点（手机能否用官方浏览器方式登录并查到额度），再做与Cursor无关、可独立交付的“不显示套餐名”；随后公共层→查询解析→登录→刷新，最后补提醒、演示并收口。每项一次对话、一个小提交。
