## 用户最终会看到什么

已添加的Cursor账户不用再登录，卡片、详情和桌面小号／中号组件上多一行“Grok Bot”，显示每周剩余百分比（App里还有下次重置时间），和Grok Bot App里看到的一致；没有Grok Bot额度的账户不显示这一行。每周重置时收到“Grok Bot 本周额度”提醒。演示账户也能看到两行效果。

## 拆分思路

查询接口不是官方公开的，先在真机证明能查到且与Grok Bot App一致（第一阶段），再做数据→显示→提醒与演示→回归（第二阶段）。显示复用Codex两行布局，不重新设计样式。
