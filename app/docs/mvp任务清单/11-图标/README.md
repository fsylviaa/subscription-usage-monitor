## 用户最终会看到什么

App里所有功能图标换成同一套Lucide线条图标，设置页“卡片样式”“深色模式”前也有图标；首页右上角连接按钮变成圆圈加号，底部“额度”是仪表盘。平台标志换成Lobe Icons的OpenAI与Cursor：连接弹层里的标志更大、灰边更少；卡片和组件里的水印比现在小一些、明显一些。

## 拆分思路

功能图标与平台标志互不依赖，但都要改“开源许可”，按两个阶段先后做，各自装机让本人看真实效果。功能图标先做主界面（本人点名的位置），再做其余图标；平台标志先换形状，再调水印大小与深浅（涉及13款全部表面的复查）。
