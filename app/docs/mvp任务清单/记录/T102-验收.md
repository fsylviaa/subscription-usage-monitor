- 来源：npm `@lobehub/icons-static-svg@1.95.1`（MIT）的 `icons/openai.svg`、`icons/cursor.svg`，Codex 账户→OpenAI，Cursor 账户→Cursor。资源名 `DesignCodex`／`DesignCursor` 不变（文件改为 `LobeOpenAI.svg`／`LobeCursor.svg`，只把 `currentColor` 换成黑色并去掉 `1em` 尺寸，保留 `fill-rule="evenodd"`，模板着色）。
- 原生形状 `OpenAIMarkShape`／`CursorMarkShape`：用一次性脚本把同一路径转为原生几何（圆弧转三次曲线），24×24 画布铺满框；三处填充调用统一改用 `PlatformMarkShape.fillStyle`（奇偶规则），镂空不被填满；霓虹派对线框水印仍为描边，线宽按框同比例。
- 开源许可：新增“Lobe Icons · MIT”（采用内容：OpenAI 与 Cursor 平台标志，`@lobehub/icons-static-svg 1.95.1`），许可原文 `LobeIcons-MIT.txt` 与上游 `lobehub/lobe-icons` 仓库 `LICENSE` 逐字节相同（SHA-256 `add9d753…c82753a`；npm 包不含 LICENSE 文件，`package.json` 声明 MIT），随 App 打包离线可读。
- 旧来源处理：核对后产品中已不再含 CodexBar 素材或代码（`Sources/Providers/Codex` 的 CodexBar 引用只是字段契约核对说明，未复制代码），故从“开源许可”清单移除 CodexBar，删除 `CodexBar-MIT.txt`（工程中原文件条目改指向 `LobeIcons-MIT.txt`）。`Resources/README.md` 历史章节保留并标注已替换。
- 不变：读屏名称、测试标识（`platforms.codex`／`platforms.cursor` 等）、点按区与连接流程。开源许可行标识由 `licenses.codexBar` 改为 `licenses.lobeIcons`（该行本身被替换），对应 T45 UI 测试同步改为检查 Lobe Icons 许可开头 `Copyright (c) 2023 LobeHub` 与末段。
