# T91 验收记录

- 日期与任务：2026-10-17，T91 公共层支持Cursor与“本月”额度（Cursor第二阶段）。
- 结果：通过（开发者自检）。
- 用户亲自验收：通过（2026-10-17 本会话，本人在iPhone 11的0.1.0（7）上按第二阶段十步验收后答复“都验证过了，都没问题……验证通过”）。
- 环境：隔离单元测试与原生 ImageRenderer 隔离渲染，iPhone 17 Pro 模拟器／iOS 26.5；只用内存固定样例，没有登录、网络或正式账户。不是真实App界面，也不是实际桌面组件。

## 本次改动

- 平台：新增 Cursor（`provider=cursor`、`product=cursorSubscription`）；账户按平台显示“Codex”／“Cursor”。存储校验平台与产品必须配对。
- 额度窗口：新增“本月”。沿用快照原有主窗口位置（存储键仍为 `weekly`，旧数据无需迁移）：Codex 放每周、Cursor 放本月；Cursor 的5小时位置固定为“确认不适用”，任何界面都不显示。“本月”的内部标记是 -1（不是秒数），保证 Codex 免费版30天窗口仍按原规则不被识别。
- 显示层：账户卡、详情额度卡、小／中号组件、“显示账户”选项副标题、详情页标题都按账户平台显示；窗口名“本月”；“本月”沿用原“每周”主窗口配色（各款原有单窗口布局）。Cursor 详情不显示 Codex 专有的“重置额度”行。
- 水印：第12款标题图标和各款右下水印改用对应平台标志。Cursor 标志取自与 Codex 标志同一 MIT 授权图标集（CodexBar `ProviderIcon-cursor.svg`，SHA-256 `01bac277…7e23ecd3`），同画布同变换；Cursor 方块是实心形状，面积比 Codex 线条标志大，透明度乘0.6保持同样低对比。
- 组件数据：组件快照新增显示用 `platform` 字段（旧快照没有该字段时按 Codex 读取）；组件点击链接的身份指纹 Codex 保持原算法不变，Cursor 用独立前缀，同一邮箱的两个平台账户不会互相打开。
