## 结论（供第二阶段 T106 使用）

**结论①：接口可用，T106 按此实现。用 App 已保存的 Cursor 会话，不需要另外登录；本人核对剩余与重置时间与 Grok Bot App 一致。**

链路：读 App 已保存的 Cursor 账户与本机授权 → 与 `usage-summary` 同一 Cookie `WorkosCursorSessionToken=<userId>%3A%3A<accessToken>` → `POST https://cursor.com/api/dashboard/get-sand-usage-status`，`Content-Type`／`Accept: application/json`、`Origin: https://cursor.com`、正文 `{}` → 200。一次成功，未用到 `api2.cursor.sh/aiserver.v1.DashboardService/GetSandUsageStatus`（Bearer）备选。

验证页显示：剩余 = 100 − `usagePercent`；下次重置 = `nextResetTimestampUtc`（本机时区显示）；有套餐内额度 = `includedLimitZero` 取反，没有该字段时取 `hasNonZeroIncludedLimit`；仅试用 = 无套餐内额度且 `sandTrialExpiresAt` 未到期。
