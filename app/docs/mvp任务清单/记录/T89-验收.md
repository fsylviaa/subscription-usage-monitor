## 结论（供第二阶段 T92／T93 使用）

**结论①：官方浏览器轮询可用，T93 按此实现，不需要改用 App 内登录页。**

链路：App 生成 32 字节 verifier、`challenge = base64url(SHA256(verifier))`、小写 UUID → 用系统默认浏览器打开 `https://cursor.com/loginDeepControl?challenge=…&uuid=…&mode=login&redirectTarget=cli&supportsSelectedTeamLogin=true` → 本人在网页登录并确认 → 回到 App → `GET https://api2.cursor.sh/auth/poll?uuid=…&verifier=…`（`Content-Type: application/json`）返回 `accessToken`／`refreshToken` → 取 access token 的 `sub` 最后一段为 user ID，构造 `Cookie: WorkosCursorSessionToken=<userId>%3A%3A<accessToken>` → `GET https://cursor.com/api/auth/me` 200 → `GET https://cursor.com/api/usage-summary` 200。Cookie 形式一次成功，未用到 Bearer 备选。
