# T85 验收记录｜账户卡与详情额度卡按对比页实现

## 2026-10-15 开发者自检

依据：`design-references/2026-10-15-紧凑改版/index.html`（d8aaec5），逐款取`STYLES[].render`的配色、结构、比例。环境：新建“T84 iPhone 11”模拟器（iOS 26.5，414×896），Debug，隔离两账户（90%／70%，`--t26-isolated-ui success`）。真实账户、授权未涉及。

实现：新增`CompactQuotaTheme`（13款浅深配色、背景、水印；霓虹派对玫红线稿水印）、`CompactQuotaBars`（13款图形，先画已用再按准确比例裁出剩余，0%／100%／小数连续；金色仪表E→F油表）、重写`QuotaStyledCard`账户卡／详情单窗口布局（12款改后排布＋霓虹派对两层纵深与激光束）。所有可见文字无“剩余”，读屏为“剩余 90%”。左右并列（金色仪表、蓝条水印）用网格共享行高；最大字号时改为上下排列。App动效：胶囊气泡、试管气泡、激光光扫与光头呼吸、油表指针从E摆入、数值变化过渡；减弱动态效果时全部静止。组件暂由旧渲染器显示（T86替换）。

回归中发现并修正的App问题：最大字号下卡片右上角刷新小转圈变大到约40pt并挤动标题（旧卡固定了尺寸），已恢复固定14pt小位置（D-60）。

需本人知悉的处理：卡片仍不显示邮箱（D-72），但为读屏增加了不可见的账户标识，开启旁白时能区分同套餐的多个账户；测试也据此识别账户。未获取额度显示“尚未获取额度”，从未成功又刷新失败显示“刷新失败”（项目统一文案，旧卡为“获取失败”）；Free等无适用额度显示“无适用额度”。重置时间按对比页显示“预计重置 · 10月16日 05:33”，不再是旧卡的“6 天后”。

测试调整（不降低检查）：账户识别改用读屏标识；第4个账户超出一屏时先滚动再核对；拖动起点改在卡片可见的标题区；样式清单改为13款。
