## 本人怎么验收

1. 手机打开“订阅用量”，在设置确认“演示模式”关闭；回额度页，记住真实账户数量及顺序（如 A、B）。
2. 点额度页右上角连接 → OpenAI 图标，按原流程在官网使用已有的 A 邮箱完成登录，再回 App。应仍只有一条 A、总数不增加、A 位置不变、其他账户不变，也没有“账户已存在”提示。
3. 彻底关闭 App 后重开，数量和顺序仍不变。在 A 卡片菜单点刷新，确认该连接能完成更新即可；本次不核对五小时余额数字。
4. 再点连接 → OpenAI 图标，出现登录代码后直接关闭弹窗，原账户及已有数据应保持。

身份核验失败、保存失败、查询失败及作用域变化由开发者隔离验证；本人无需制造错误或切换工作区。真实流程若出现失败，可告知停在哪一步和界面文字；不会据此自动删除旧连接。
