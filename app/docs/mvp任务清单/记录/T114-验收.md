## 2026-10-19 协作者真机反馈与修复：点“粘贴”闪退

**反馈**：协作者在 iPhone 14／iOS 18.1.1 的 Debug 0.1.0（20）上进入 DeepSeek key 输入页，点输入框右侧“粘贴”后 App 立即退出；要求修复。

**证据与原因**：从该手机取回4份连续复现的崩溃日志。最新日志异常为 `EXC_BREAKPOINT`／`SIGTRAP`，故障线程依次出现 `_dispatch_assert_queue_fail`、`swift_task_isCurrentExecutorImpl`、`APIKeyEntryView.body` 粘贴回调和 SwiftUI `PasteHelper`。原实现的系统 `PasteButton` 在非主队列交付内容，但回调捕获了由 SwiftUI 主执行器隔离的 `key` 状态；Swift 6 在进入回调时先做执行器检查，因此尚未来得及执行回调内的 `Task { @MainActor ... }` 就已触发队列断言。该问题与 key 内容、网络、签名或剪贴板权限无关。

**修改**：把输入框右侧的系统 `PasteButton` 换为普通 SwiftUI `Button`。按钮的主线程动作直接读取 `UIPasteboard.general.string`，去除首尾空白后写入安全输入框；保留原按钮样式、禁用状态和无障碍标识。未修改 key 校验、余额请求、保存或账户数据逻辑。
