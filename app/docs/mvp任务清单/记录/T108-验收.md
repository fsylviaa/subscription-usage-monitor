## 实现

- 提醒：共用现有总开关和权限判断。每个有 Grok Bot 额度且有未来重置时间的 Cursor 账户单独安排一条，标题同其他提醒“Cursor · 邮箱”，正文“Grok Bot 本周额度预计重置，打开查看”，时间为 Grok Bot 下次重置时间。标识沿用现有格式（窗口位用“每周”，Cursor 没有其他每周窗口，不会与“本月”冲突），点击通知与其他提醒一样进入对应账户详情。本月额度不可用时 Grok Bot 提醒仍按其自身数据安排。
- 不安排：无套餐内额度、从未取得、没有或已过重置时间、演示账户、开关关闭／未授权。重置时间变化替换旧提醒，删除账户或不再适用时取消，同轮不重复（沿用现有调度器）。
- 演示：开启演示时的 Cursor 示例账户同时有“本月”和“Grok Bot”两行（本地模拟数据，Grok Bot 重置在3天后）；单账户刷新时两行一起变化；演示账户不安排真实通知；关闭演示一并清除。
