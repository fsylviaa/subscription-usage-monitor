## 用户最终会看到什么

“连接账号”弹层多出OpenRouter、DeepSeek两格。点进去粘贴自己已有的key（OpenRouter填管理密钥），App验证查到余额后就添加账户，不用开浏览器。卡片、详情和桌面小号／中号组件显示“余额”金额，和两家网站上看到的一致；DeepSeek详情还能看到充值和赠送余额。之后自动刷新，失败保留旧金额。演示开关也有这两家的示例。

## 拆分思路

先在真机用真实key证明两个余额接口可用、与网站一致，并确认OpenRouter普通key会被拒（第一阶段）。再按数据→查询→连接→显示→演示与提醒→回归实现（第二阶段）。显示沿用现有卡片、详情与组件结构，只把额度区换成金额，不重新设计样式。
