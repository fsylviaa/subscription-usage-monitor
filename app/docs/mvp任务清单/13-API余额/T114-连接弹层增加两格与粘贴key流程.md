## 本次交付与范围

- “连接账号”弹层在Codex、Cursor之后增加OpenRouter、DeepSeek两格，Lobe Icons官方标志＋格内平台名（同D-78／D-79），浅深与大字号适配；补充开源许可中实际用到的标志。
- 点击→新增前网络检查（未通过按现有提示）→弹层内原生输入页：一个粘贴key的输入框和“连接”按钮；OpenRouter页简要说明需填管理密钥（Management key）及创建路径：openrouter.ai 左上角两条杠菜单 → Account（账户）分组 → Management Keys → 创建（本人2026-10-18实测；不是顶部Settings），一两句即可，不展开教程。不打开浏览器，无创建key或充值步骤。
- 点“连接”→用该key查一次余额→成功才建账户（同key原位更新，否则追加末尾）并关闭弹层；被拒或失败不建账户，在弹层内简短提示、可修改后重试，不罗列技术原因。
- 输入框为安全输入（不出现在截图建议、不进入日志），返回或取消即丢弃内存中的key。
