## 本次交付与范围

在现有一套账户与额度框架中加入“余额类”账户，不与订阅窗口混用：

- 平台：新增OpenRouter、DeepSeek两个平台标识；账户身份为key末四位（如“sk-…a1b2”），不编造邮箱。
- 凭据：key只存钥匙串（沿用现有CredentialVault），按平台＋key指纹识别重复；同平台同一把key再添加即更新原账户、位置不变，不同key各成账户。
- 数据：余额快照按币种保存Decimal金额（总余额，DeepSeek另存充值／赠送），保存获取状态与最后成功时间；没有窗口、百分比和重置时间。缺字段为未知而非0；失败保留可信旧值和原成功时间。
- 旧版数据文件可读，不影响已有Codex／Cursor账户；删除账户移除key与缓存；组件共享数据只放展示所需金额，不放key。

不在本项：网络请求与解析（T113）、连接界面（T114）、显示（T115）、演示与提醒（T116）。
