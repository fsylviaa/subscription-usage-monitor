## 2. 网络检查与失败恢复

评分来源统一为 `https://ip.net.coffee/claude/` 的 Claude AI 信任评分。下列全部用模拟结果验证，不能通过真实网站结果代替边界场景。

| 编号 | 操作与样例 | 通过条件 |
|---|---|---|
| R4-N01 | 新增账户 → 检查中 | 显示轻量动态反馈；实际授权与添加尚未开始，没有新账号记录；可按来源取消／返回 |
| R4-N02 | 新增／查询 → 有效评分 49 | 明确显示 49、“需高于 50 才能继续”及不能继续的原因；阻止操作，可重试或退出 |
| R4-N03 | 新增／查询 → 有效评分 50 | 与 49 一样被阻止，不能把等于阈值算通过；显示当前 50 和通过条件 |
| R4-N04 | 新增／查询 → 有效评分 51 | 自动继续原授权或查询，身份和操作范围不变；检查通过不能直接视为额度成功 |
| R4-N05 | 检查超时 | 显示无法完成网络检查和超时原因，无虚构评分；不新增、不查询，可重试、取消或返回 |
| R4-N06 | 网站不可用 | 显示无法完成网络检查和网站不可用原因，无虚构评分；不新增、不查询，可重试、取消或返回 |
| R4-N07 | 无有效评分 | 显示无法完成网络检查和未取得有效评分原因，不写 0 分、低分或假数值；不新增、不查询，可重试或退出 |
| R4-N08 | 任一检查失败 → 重试 → 51 | 重新进入检查中，通过后继续原操作；不跳过检查，不扩大为其他账户或其他动作 |
| R4-N09 | 失败 → 取消／关闭／返回 | 返回真正来源页并保留账户、选定对象与合理展开状态；没有无法关闭弹层或新建账号 |
| R4-N10 | 新增前通过 → 授权取消／失败／退出登录 | 区分授权结果与检查结果，不创建新账号，不改变已有账号；返回发起添加的来源并可重新添加 |
| R4-N11 | 检查通过 → 额度查询失败 | 显示查询失败；保留可信旧额度与原成功更新时间，无缓存时明确无法获取；不显示刷新成功、不伪造满额或零额 |
| R4-N12 | 查询失败 → 重试 | 必须重新检查；通过后才再查询，成功才变更该账号的额度与成功时间 |
