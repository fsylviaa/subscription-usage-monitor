# Token Dashboard

> Token 仪表盘

## 一句话

所有 AI 订阅的剩余额度，抬手即见。

## 卡片短介绍（约 60 字，适合作品列表）

一款 iPhone 上的 AI 订阅用量仪表盘。把 Codex、Claude、Cursor 等主流 AI 平台的剩余额度和 API 余额集中到一屏，桌面小组件直接显示，并将推出 Apple Watch 表盘。

## 标签

`iOS` `SwiftUI` `WidgetKit` `Apple Watch` `AI 工具` `效率`

## 项目详情

### 为什么做它

现在写代码离不开好几个 AI 订阅：这家有 5 小时额度，那家按周重置，还有几个按 API 余额扣费。想知道"还剩多少、什么时候重置"，只能挨个打开官网或命令行去查。用得越多，查起来越麻烦，常常是额度用完了才发现。

Token 仪表盘就是为此做的：把分散在各平台的用量收到一个地方，打开手机就能看清。

### 它能做什么

- **一屏看全部**：每个账户的 5 小时额度、每周额度、重置时间和 API 余额，以统一的卡片排在一起，剩余部分高亮显示，已用部分用灰色区分。
- **主流平台都能接**：覆盖 Codex、Claude、Cursor、Grok、Antigravity、Kimi、智谱 GLM、MiniMax、Qoder、DeepSeek、OpenRouter、OpenCode、Muse Code、Command Code 等 14 个以上平台，更多平台持续接入。
- **多账户**：同一平台可以添加多个账户，顺序长按拖动即可调整。
- **桌面小组件**：小号、中号组件直接显示额度，每个组件可以单独选择要看的账户。
- **自动更新**：打开 App 立即刷新，后台定期同步，不需要手动刷新。
- **连接简单**：订阅类平台通过官方页面登录授权，API 类平台粘贴已有密钥即可；登录凭据只保存在本机钥匙串。

### 下一站：Apple Watch

额度会做成 Apple Watch 表盘和复杂功能。写代码时不用掏手机，抬一下手腕，就知道这周的额度还够不够用。（规划中）

### 设计理念

能简化就简化。用户只想知道还剩多少，所以界面上只有额度、余额和重置时间，没有技术术语和多余设置。出错时只给一句看得懂的提示和一个重试按钮，并且始终保留上一次成功的数据，不会把失败显示成满额或者零。
